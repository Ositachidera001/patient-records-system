# Patient Records System

## 🏷️ Domain
**Health IT** — Patient registry and triage system

## 📋 Description
A Python tool that registers patients, classifies them by urgency level, and dispatches them to the appropriate care unit. Built as part of Lesson 9 (Functions) in the Python Foundation track.

## 🚀 How to Run
1. Clone the repository
2. Navigate to `src/`
3. Run:
   ```bash
   python main.py
